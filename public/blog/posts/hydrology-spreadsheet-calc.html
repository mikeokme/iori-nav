用电子表格做水文水力计算：频率分析、流量推求与水量平衡

2026-11-01 · 水利与工程 · 「醉生梦死导航」维护者

做水文、水工计算，工程师十有八九还是拿 Excel 或电子表格来算——不是没更好的工具，而是它参数集中、公式可追溯、改一个数全表自动重算，还顺手能出图。但表格也有它的老毛病：最容易算错、还错得没人发现。这篇把几个最常用的计算（频率分析、流量推求、水量平衡）「怎么做表、公式怎么放、哪些坑要盯」过一遍，是实操向的，不展开推导。

为什么用表格算，还能算得稳

  • 参数集中在一处：改一个水文参数，下游全表自动重算，不用手翻着改；
  • 公式可见可追溯：审查时能逐格对，不像黑盒软件只能信输出；
  • 能直接出图：频率曲线、流量过程线，生成好就能往报告、答辩里放；
  • 但要记住：别把「查表值 / 拟合结果」当死数敲进去（下面频率分析会说）。

频率分析（洪水 / 降水频率）怎么做表

先把多年最大系列（最大流量、年最大洪峰、年最大雨量……）按大小排好，配频率曲线。工程上最常用的是皮尔逊 III 型（P-III），三个统计参数是均值 X̄、变异系数 Cv、偏态系数 Cs。

设计值的标准写法：

X_p = X̄ · (1 + Cv · Kp)

其中 Kp 由 Cv、Cs 和设计频率 P 三者共同决定，要用适线法配线、再查 P-III 值表（或对应公式）算出来。常用设计频率是 P=1%、2%、5%、10%、20%、50%。

最大的坑：Kp 不是固定常数，它随 Cv、Cs 和 P 变。千万别用一个 Kp 套所有频率。表格里放一列 Cv / Cs，逐个频率算 Kp、逐个频率出 Xp。这样 Cv、Cs 改一个数，所有频率的设计值一起变，审查时一眼就能看出敏感性。

流量 / 水力要素推求

  • 水位—流量关系（率定）：把水位与实测流量配成关系曲线，表格画散点 + 拟合，得到 Q = ƒ(H)，之后有水测得水位就能推流量；
  • 明渠断面：Q = A·v，A 由断面几何算，v 用曼宁公式 v = (1/n)·R^(2/3)·i^(1/2)。把水力半径 R、比降 i、糙率 n 放成参数列，改断面尺寸就自动重算；
  • 两个易错点：曼宁公式里 R 是水力半径（过水断面面积 / 湿周），别误用几何半径；糙率 n 取值对结果影响很大，查手册别拍脑袋。

水量平衡（调节计算）

基本式：W_{t+1} = W_t + (Q_入 − Q_出 − E − 其他损失)·Δt。

表格里按时间步（月 / 日）逐行往下推，W_t 就是上一行的结果，形成滚动计算，一路推到底就能看蓄水过程。两个坑：Δt 单位要对齐（流量 m³/s × 时间要统一换算，或直接用 m³/月）；还要单独校核「满库 / 空库」两个边界，别只看中间值。

工程计算通用：表格的四个雷区

  • 别把「查表 / 拟合结果」直接敲成死数字，保留公式，可追溯、可重算；
  • 关键结果加一行「校核」：用独立公式或手算复核一遍，跟表里对得上再往下走；
  • 输入参数单独放一块、上色标「输入区」，别散落在各条公式里；
  • 提交 / 汇报前，导出一份「公式可见」的版本存档，真出了争议能查当时到底怎么算的。
