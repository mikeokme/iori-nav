策展指南：本站怎么选、怎么养、怎么更新

更新于 2026-11-12

这一页回答三个问题：站内链接从哪来、由谁维护、你能怎么参与。如果只记一句：**精选型导航站的价值是「可用性」，不是「链接数量」。**

一、为什么不做成大聚合站

聚合型站点用「爬虫海选 + 人工抽检」一次甩给你几千条链接，代价是里面一半带着弹窗、跳转陷阱或者已经停更，用户反而要花同样的时间去筛。本站反着做：354 条链接全部人工过筛，入库后再定期复检。「反向筛选」的意思是——不问「什么火」，只问「值不值得留下来」。

代价也要说清楚：覆盖面远小于聚合站。找不到某个站，通常是它没过三道筛，而不是我们忘了收。

二、三道筛：每条链接都要过

  • **可用性**：目标站在线、能正常打开，不是 404，不是强制注册才能看内容；
  • **无垃圾**：无强制弹窗、无跳转陷阱、无诱导注册、无挡内容的广告墙；
  • **确能用**：用一次能解决一件具体的事，而不是「看着酷」的玩具。

入库不是一锤子买卖，链接会被定期复检，剔除标准固定：

  • 失效或换域名 → 当天替换同质量入口，收藏夹不用重存；
  • 开始弹广告、要求注册 → 直接剔除，换更干净的同类；
  • 索引半年不更新（网盘搜索类）→ 到期剔除；
  • 限速严重、存活率差（分享盘类）→ 观察一个月，不达标剔除。

三、分类体系：12 个一级分类各管一摊

首页一级分类是固定的，子分类允许长出来，但职责不重叠：

  • **AI助手 / AI创作与模型**：对话、AI 搜索、图像生成、模型平台，日常 AI 动线的入口；
  • **常用与工作**：高频日常入口；
  • **水利与工程**：政务检索、质量安全、项目平台，按业务动线组织（用法见博客《水利专区使用手记》）；
  • **办公与学习 / 影音与媒体**：办公、笔记、学习、视频、网盘；
  • **开发与云服务 / 网络与安全**：主机、代码、云、VPN、网络检测；
  • **域名与邮箱 / 生活与购物 / 资讯与社区 / 其他网站**：一个场景一类，互不串味。

分类调整（合并、改名）会提前在博客公告，老链接保留 30 天 301 跳转。

四、维护承诺（SLA）

  • 失效链接：当天修复，替换入口走同一套三道筛；
  • 用户推荐站点：48 小时内人工实测 + 三道筛，结果邮件告知；
  • 每月全量复检一遍 354 条；
  • 重大变化（分类、入库规则）先在博客发说明，再动手。

五、广告与收入披露

  • 本站唯一收入来源是 Google AdSense，广告单元只出现在博客页和首页一处，已按规范披露在 ads.txt；
  • **不接受付费收录，这一点不会变**——卖收录位等于把三道筛架空，策展站做了这件事就不再是策展站；
  • 广告展示与否不影响任何链接的收录与排序，代码不读取任何广告侧数据。

六、怎么参与

  • 推荐站点：走「联系我们」页，四样信息：URL、建议分类、推荐理由（它解决了什么任务）、是否免费；
  • 报失效链接：同一页面，当天修；
  • 阅读动线：每周一的周报 → 场景专栏 → 首页分类 → 推荐/反馈。

导航站是读者共同维护的产品：你用、你报、它长。
